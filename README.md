### What Crawlbench does

Crawlbench watches Facebook Marketplace on a schedule, runs every listing through a strict match gate, and pings you (email or Telegram) when something clears your buy box — so you open Messenger while the listing is still warm.

Depth on one source. Not a thin layer across many marketplaces.

### Built for operators

- **Advanced filters** — price, location, keywords, exclude terms, and category-specific fields
- **Multi-city coverage** — monitor many metros without babysitting tabs
- **Match alerts** — email digests and Telegram (`@CrawlbenchAlertsBot`) when a listing passes
- **Team workspaces** — one buy box and one match queue for the desk
